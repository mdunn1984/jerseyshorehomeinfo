# Page Standards

The quality bar every page on jerseyshorehomeinfo.com must meet. Use this as a checklist when building or reviewing a page. A page is not "done" until it satisfies these standards.

## 1. Universal requirements (every page)

- Unique, descriptive title tag and meta description (SEO/AEO aligned).
- Clean semantic HTML structure with a single clear H1.
- Consistent global header and footer (navigation, brand, contact).
- Mobile-responsive layout.
- Correct UTF-8 encoding with clean punctuation (no mojibake / garbled characters).
- Real images only — no "PHOTO PLACEHOLDER" text in production.
- Working internal links; no dead links.
- Required compliance footer: brokerage, NJ License #2442118, Equal Housing Opportunity, Fair Housing, and the "believed accurate but not guaranteed" disclaimer.
- At least one clear call to action (View Homes, Free Valuation, or Contact).

## 2. Town page standard

Each town page should include:

- Hero with a real local image and the town name.
- Quick-stats block (for example median sale price, population, notable facts) — verified figures.
- "About" section describing the town and its real estate character.
- Schools section.
- Recreation / parks section.
- Amenities and points of interest.
- A closing CTA to view homes or request a valuation.
- Internal links to related towns and the search page.

## 3. Search and homepage standard

- index.html: clear value proposition, office listings IDX, and primary CTAs.
- search.html: working FBS SmartFrame MLS search; do not wrap it in redundant custom filter UI.

## 4. Guide page standard (for example relocation guides)

- Clear audience and purpose stated up front.
- Practical, specific, locally accurate information.
- CTA to connect with Matt Dunn.

## 5. Legal page standard

- privacy-policy, terms-of-service, and fair-housing present and current.
- Site-specific content (not generic boilerplate where specifics are required).

## 6. Trust elements (target state)

- Agent headshot and short bio.
- Weichert brokerage branding.
- Credentials and licensing.
- Client reviews or testimonials.

## 7. Review checklist

Before marking a page done: encoding clean, images real, links working, CTA present, compliance footer correct, mobile layout verified, and SEO metadata set. Log the result in CHANGELOG.md.
