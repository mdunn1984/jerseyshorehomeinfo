# Jersey Shore Home Info

The website for jerseyshorehomeinfo.com, the digital real estate platform of Matt Dunn, REALTOR (Weichert Realtors, Ship Bottom, NJ). It is a local-authority resource for buyers and sellers across Ocean County and Long Beach Island, combining town guides, live MLS home search, and lead capture.

## Tech at a glance

- Static HTML site (one file per page at the repo root).
- Hosted on Netlify.
- Listings via FBS SmartFrame IDX (MLS search on search.html, office listings on index.html).
- Single working branch: main.
